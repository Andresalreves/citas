# Tinder Clone      
[![es](https://img.shields.io/badge/lang-es-yellow.svg)](https://github.com/juan-canseco/tinder-clone/blob/master/README.es.md)

![Alt Text](https://media.giphy.com/media/oeo5NJ91RjgjSGMoKv/giphy.gif)

Tinder Clone developed with [Kotlin](https://developer.android.com/kotlin), the architecture of this project is heavily inspired in the repository of [Clean Architecture](https://github.com/android10/Android-CleanArchitecture-Kotlin) from Fernando Cejas.
## Features 
- Authentication (Google, Phone Auth, Email)
- On Boarding (Profile creation)
- Home Screen (In Development)
- Testing (Unit Testing, Android Testing, Instrumented tests coming soon…)

The app is still under development, it will be updated regularly.

## Demo
If you want to test the app you can find the apk in this [Link](https://drive.google.com/file/d/1UXCKNk6tgPWvQTp8SzcMeNtIns-vC_sW/view?usp=sharing).
Note: please disable dark theme in your phone for optimal experience.

Tinder Clone is possible thanks to the following technologies:
- [Android SDK](https://developer.android.com/) 
- [Android Jetpack](https://developer.android.com/jetpack) - LifeCycle, Fragment, Hilt, Databinding, Navigation Component
- [Firebase](https://firebase.google.com/docs/android/setup?hl=es-419) - Authentication, Firestore, Firestorage
- [Coroutines](https://developer.android.com/kotlin/coroutines)
- [Progress Button](https://github.com/razir/ProgressButton) -  razir/ProgressButton

- [JodaTime](https://github.com/dlew/joda-time-android) -  dlew/joda-time-android
