# Tinder Clone      
[![en](https://img.shields.io/badge/lang-en-yellow.svg)](https://github.com/juan-canseco/tinder-clone/blob/master/README.md)

![Alt Text](https://media.giphy.com/media/oeo5NJ91RjgjSGMoKv/giphy.gif)

Clon de Tinder desarrollado con [Kotlin](https://developer.android.com/kotlin), la arquitectura del proyecto está inspirada fuertemente en el repositorio de [Clean Architecture](https://github.com/android10/Android-CleanArchitecture-Kotlin) de Fernando Cejas.
## Características 
- Autentificación (Google, Numero de Teléfono, Email)
- OnBoarding (Creacion de perfil)
- Pantalla principal (En desarrollo)
- Pruebas (Unitarias, Android, Instrumentadas próximamente)

La aplicación todavía está en desarrollo, se estará actualizando regularmente.

## Demo
Si quieres probar la app puedes encontrar el apk en el siguiente [Link](https://drive.google.com/file/d/1UXCKNk6tgPWvQTp8SzcMeNtIns-vC_sW/view?usp=sharing). Nota: para poder tener una experiencia optima por favor deshabilita el tema oscuro de tu teléfono.

## Tecnologías

Tinder Clone es posible gracias a las siguientes tecnologías:

- [Android SDK](https://developer.android.com/)

- [Firebase](https://firebase.google.com/docs/android/setup?hl=es-419) - Authentication, Firestore, Firestorage
- [Coroutines](https://developer.android.com/kotlin/coroutines)
- [Progress Button](https://github.com/razir/ProgressButton) -  razir/ProgressButton
